# remindLiza — weekly planner

Простая веб-заметочница/планировщик недели.

## Что уже есть

- Бэклог задач слева.
- Перетаскивание задач в календарь.
- Перемещение встреч между днями и временем.
- Изменение длительности встречи нижним краем карточки.
- Простая локальная база данных через `localStorage`.
- Данные сохраняются после перезагрузки страницы.

## Как открыть

Можно просто открыть `index.html` в браузере.

Или запустить локальный сервер:

```bash
python3 -m http.server 8080
```

Потом открыть:

```text
http://localhost:8080
```

## Структура

```text
index.html   # HTML-разметка
style.css    # внешний вид
app.js       # логика календаря и localStorage-база
README.md    # описание проекта
```
